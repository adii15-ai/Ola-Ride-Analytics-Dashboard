# 🚕 Ola Ride Analytics Dashboard — Power BI

## 📌 Project Overview

This project is an **Ola Ride Analytics Dashboard built using Microsoft Power BI**. The dashboard analyzes ride-booking data to provide insights into booking volume, booking status, revenue, cancellations, vehicle types, and customer/driver ratings.

The objective of this project is to transform raw ride-booking data into an **interactive business intelligence dashboard** that helps identify important operational and customer trends.

---

## 🎯 Objectives

The main objectives of this project are to:

* Analyze overall Ola ride-booking performance.
* Track total bookings and booking values.
* Understand ride volume trends over time.
* Analyze successful and unsuccessful bookings.
* Identify booking status patterns.
* Analyze revenue generated from successful bookings.
* Compare different vehicle types.
* Study cancellation patterns.
* Analyze customer and driver ratings.
* Provide an interactive dashboard for business decision-making.

---

## 📊 Dashboard Pages

The Power BI report contains the following analytical sections:

### 1. Overall Dashboard

Provides a high-level overview of Ola's ride-booking performance.

Key components include:

* **Total Bookings**
* **Booking Values**
* **Ride Volume Over Time**
* **Booking Status Breakdown**
* **Date Filter**

The ride-volume chart helps analyze booking trends across different dates, while the booking-status visualization provides an overview of successful and other booking outcomes.

---

### 2. Vehicle Type Analysis

This section focuses on the performance of different vehicle categories.

Possible insights include:

* Booking volume by vehicle type
* Revenue by vehicle type
* Vehicle-type performance comparison
* Customer preferences
* Ride distribution across vehicle categories

This analysis can help identify which vehicle categories contribute most to Ola's overall business.

---

### 3. Revenue Analysis

The Revenue dashboard focuses on the financial performance of rides.

Key analysis includes:

* Total booking value
* Revenue contribution
* Revenue trends
* Revenue comparison across categories
* Successful booking value

The dashboard can be used to understand which segments generate the highest monetary value.

---

### 4. Cancellation Analysis

This section analyzes ride cancellations and their potential impact on operations.

Key areas include:

* Booking cancellations
* Cancellation patterns
* Customer-side cancellations
* Driver-side cancellations
* Cancellation trends

Understanding cancellation behavior can help identify operational issues and improve ride completion rates.

---

### 5. Ratings Analysis

The Ratings dashboard focuses on customer and driver feedback.

The analysis can be used to understand:

* Customer ratings
* Driver ratings
* Rating distribution
* Performance differences between ride categories
* Overall service quality

These insights can help identify areas where customer experience and driver performance can be improved.

## 🧹 Data Preparation

The following data-preparation activities were performed:

1. Imported the ride-booking dataset into Power BI.
2. Cleaned and transformed the raw data using Power Query.
3. Checked data types and column consistency.
4. Handled missing or inconsistent values where required.
5. Created relationships/data model required for analysis.
6. Created DAX calculations for important KPIs.
7. Built interactive visualizations.
8. Added filters/slicers for dynamic analysis.
